# JZ01 — HS16P2811

打开工程：PROJECT/JZ01.hsprj2（HSIDE 2.1.16）。

源码沿用复制的FanForge F824无刷固定电压7+3基线，在main.c/main.h内修改，保留成熟函数职责、顺序和编程风格。

## 已实现
- 用户确认16MHz/4T，工程配置及T1理论100us重载0xFE70一致；2脚PA7/T3PWM3继续使用原基线外设路线和7+3相位推进。
- 10脚PC1/AIN5、2V参考、100kΩ:10kΩ分压，固定9V比较目标3350（原始均值×2），与fan_mode档位无关，无旧板200mV补偿。
- 真实反馈ADC路径、连续13个超限均值保护，初版10V阈值；ADC连续超时3次时停升压并置故障。保护阈值与响应需板测。
- 6脚PC5制冷使能、7脚PC4升压导通沿用成熟结构，保留启停间隔路径。
- 3脚PA6/AIN13三路AD输入的区间识别、去抖、短按/长按事件。KEY1=20k、KEY2=0Ω、KEY3=6.8k；所有按键产品动作按用户要求留空，KEY_deal目前只清事件。
- CHRG/STDBY充电状态及电量处理保留基线。电量补偿和百分比阈值为参考值，需JZ01电池板测标定。

## 按要求留空
- 8脚PC3的电机档位PWM/频率/通信协议：只初始化低电平，不发送。
- S1-S6：PA0/PA1/PA2/PA3/PC0/PC2全部输入，不使用参考段码驱动。
- 按键具体功能：无自动启动/调档/制冷动作，补功能后在KEY_deal填充。

## 构建和验证
在项目根目录执行：

```powershell
python build.py
python verify.py
```

原生HSIDE cc1.exe + PICC 9.83构建：0错误、0警告；ROM 1732/2048 words、RAM 67/128 bytes。
产物：PROJECT/JZ01.hs.hex、PROJECT/JZ01.ccs；详细结果见build_report.txt、build_result.json。
verify.py覆盖9V换算、344种7+3粗细组合、ADC容量/故障路径、三键区间/空动作、占位引脚及工程/HEX一致性。

这是可编译的初版工程。尚未做HSIDE GUI重建或物理板验证。100us是重载理论节拍，PWM频率及稳压误差/纹波/负载瞬态须示波器和板测确认。三AD电阻组合同时接通的电平尚未定义，当前只识别单支路区间。恒压情况下仅凭输出电压不能保证检测到所有电机缺失，需板测确认超压特征或补充可用的电机反馈依据。
