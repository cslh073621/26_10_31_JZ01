# JZ01 — HS16P2811

打开工程：PROJECT/JZ01.hsprj2（HSIDE 2.1.16）。
源码从复制的FanForge F824无刷固定电压7+3固件直接修改，保留成熟函数结构。

## 操作
- 0Ω开关键：长按单次开机/关机，每次开机从1档开始；开机时双击切换制冷。单击无动作，持续按住不反复开关。
- 6.8kΩ加档、20kΩ减档均按回弹按键处理：短按±1，长按连续±1；档位范围1..100，到边界停止；关机时加减键不启动设备。
- 沿用基线充电禁止制冷规则；开机制冷时亮制冷标。

## 显示
- 开机始终显示档位与百分号，不切电量页，个位档不显示前导0。充电开机仍显示档位；关机充电188熄灭。
- S1-S5采用FanForge标准188段码，S6是新增五LED共阴极。沿原1ms扫描位置保留五个188槽，新增第六电量槽；100us的7+3中断及原升压路线不变。
- 五灯累计表示电量：S5=1..20%、S4=21..40%、S3=41..60%、S2=61..80%、S1=81..100%。正常时当前区间及较低区间亮；0%全灭。
- 充电时当前区间灯闪、较低区间常亮。只有STDBY满充状态且电量100%时五灯全常亮；电量100%但仍处于充电状态，最高灯继续闪。
- 启动前上电自检窗口沿用基线；正常关机且未充电不显示。先将共享脚全部切输入，再切换本槽的电平和输出方向。

## 升压与保留项
- 用户确认HS16P2811、16MHz/4T；T1理论100us重载0xFE70，2脚PA7/T3PWM3作7+3升压，7脚PC4使能，6脚PC5制冷。
- 10脚PC1/AIN5，100kΩ:10kΩ分压、2V参考，固定9V目标3350（原始均值×2），所有档位不改变升压目标。
- 真实反馈采样、10V初版超压阈值及13个连续有效均值确认、ADC连续3次超时停升压保留。电池标定/补偿仍为参考参数，需板测。
- 8脚PC3已启用独立T4PWM：目标25kHz，1档35%（224/640，高14us），100档97.5%（624/640，高39us）；中间档位线性取最近整数，100档逐点核验。占空计数为224+round(400*(gear-1)/99)。
- T4使用Fosc16MHz/1，周期按FanForge计数口径写639；T3升压周期不变。T4在升压PWM启动后的下一10ms任务启用，关机/过压/ADC连续超时/睡眠均关闭输出并将8脚拉低。
- 上述频率和端点脉宽是FanForge计数口径下的理论值；手册周期公式文字与+1计数口径存在差异，必须示波器核验。调档时10位占空比的高低字节更新瞬态也需板测。
