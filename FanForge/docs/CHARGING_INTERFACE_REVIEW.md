# 充电接口模块审查

## 1. 模块边界

充电接口模块只负责把硬件输入归一成：

- `insert_flag`
- `charge_on_flag`
- `charge_max_flag`

电量映射、充放电定时追赶、充电限档、制冷约束、显示切换和睡眠资格仍由原有成熟函数处理，不为不同充电芯片复制第二套业务。

## 2. CHRG加STDBY

`chrg_stdby_active_low`使用两个内部上拉、低有效输入：

| CHRG | STDBY | 归一状态 |
| --- | --- | --- |
| 0 | 1 | 充电中 |
| 1 | 0 | 充满 |
| 1 | 1 | 未插入 |
| 0 | 0 | 按成熟程序优先归入充电中 |

生成器不启用内部上下拉。启用睡眠时，两脚都参与Port A变化唤醒。

## 3. 静态CHRG加CHRG_MAX

`chrg_chrg_max_active_low_static`使用两个内部上拉、低有效的静态输入：

| CHRG | CHRG_MAX | 归一状态 |
| --- | --- | --- |
| 0 | 1 | 充电中 |
| 1 | 0 | 充满 |
| 1 | 1 | 未插入 |
| 0 | 0 | 按成熟程序优先归入充电中 |

该类型沿用WZ02类成熟静态判断，只把第二个状态脚命名为`CHRG_MAX`。生成器不启用内部上下拉；启用睡眠时，两脚都参与Port A变化唤醒。

该类型不能用于IP5402/5307一类用周期闪烁、脉冲频率或充放电复用状态表达业务的芯片。生成器当前不生成波形计数窗口、放电状态或低电外放状态。

## 4. INSERT加CHRG

`insert_active_high_chrg_active_low`使用：

- `INSERT`：内部下拉，高有效。
- `CHRG`：内部上拉，低有效。

| INSERT | CHRG | 归一状态 |
| --- | --- | --- |
| 0 | 任意 | 未插入 |
| 1 | 0 | 充电中 |
| 1 | 1 | 充满 |

INSERT的内部下拉在工作态和睡眠态都保留；启用睡眠时，INSERT和CHRG都参与Port A变化唤醒。

## 5. 无充电接口

`kind=none`时：

- 不要求`CHRG`、`STDBY`、`CHRG_MAX`或`INSERT`脚。
- 不生成`charge_on_flag`和`charge_max_flag`。
- 不申请充电上升追赶计时资源。
- `insert_flag`保持为0，电量系统只执行成熟的放电追赶和低电关机。

## 6. 保持不变

本模块没有修改：

- `ADC_Sample()`电池采样与初始化。
- `v_bat_deal()`分段映射、负载补偿和放电追赶。
- 充电显示由`insert_flag + charge_num`决定闪烁或常亮的规则。
- 无刷风扇启动和关闭10ms顺序。
- AD_FAN 16V过压保护。
- 五线188扫描映射。

生成结果仍需经过HSIDE/PICC编译，以及实板插拔、充电、充满、睡眠唤醒和待机功耗验证。
