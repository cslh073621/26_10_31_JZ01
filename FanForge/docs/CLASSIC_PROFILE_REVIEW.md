# HS2811完整经典产品配置审查

## 1. 支持范围

当前完整配置固定支持：

- HS16P2811 SOP16。
- 两个低有效数字按键。
- 可选`CHRG/STDBY`双低有效状态输入、静态`CHRG/CHRG_MAX`双低有效状态输入，或`INSERT`高有效加`CHRG`低有效状态输入。
- 固定占空比无刷风扇。
- 独立制冷输出，充电时强制关闭。
- 五线 Charlieplex 188 数码管，制冷标和百分号映射。
- 内部 AIN12 `VDD/4` 电量采样和外部 `AD_FAN` 采样。
- 分段电量映射、负载压降补偿和充放电定时追赶。
- 约2秒全亮自检、电量直接初始化、低电提示和睡眠唤醒。

它不是自由组合代码。配置不属于上述组合时，生成器应拒绝而不是临时拼接未知逻辑。

## 2. 资源生成

功能模块分别声明 GPIO、PWM、ADC 和时间需求，规划器统一生成：

- 正常和睡眠状态的 `PORTA/PORTC`、`TRISA/TRISC`、上下拉及 `WUACON`。
- PWM脚对应的 Timer3 通道、`PWMSEL/PWMSEL1`路由、分频和周期。
- AIN12 电量通道和 `AD_FAN`通道的轮询、废样、八次平均及电量二级平均。
- 1ms、10ms、100ms、500ms、3s和四组独立电量追赶时间资源。

生成后的 C 代码直接写寄存器，不保留运行时资源表。

## 3. 输入和模式

`KEY_CHECK()`只完成两个按键的消抖、长短按计时和事件置位。

`KEY_deal()`：

- KEY1短按按配置的档位序列循环，最后回到0。
- 充电时只经过不高于`charge_max_gear`的档位，仍能从最高允许档关机。
- 配置允许时，KEY1长按连续加档，KEY2长按连续减档。
- KEY2短按只在风扇开启且未充电时切换制冷。

`mode_change()`统一处理：

- 配置选定的充电接口到充电、充满和插入状态的归一。
- 充电限档、制冷关闭、低电和风扇异常关机。
- 插拔充电器、风扇档位变化和关机后的显示状态收敛。

## 4. 显示

正常状态下，开机或调档后执行：

```text
档位3s -> 电量3s -> 常态档位
```

充电状态下，调档后执行：

```text
档位3s -> 常态电量
```

插入充电器立即显示电量，拔出充电器且风扇运行时立即显示档位。

`show_mode_deal()`先用局部变量生成三个显示字节，再短暂关闭全局中断后一次性写入`Data[0..2]`。

充电可见状态只由`insert_flag + charge_num`决定：

- `charge_num < 100`时按配置目标闪烁。
- `charge_num >= 100`时保持常亮。
- `charge_on_flag/charge_max_flag`只参与电量追赶，不覆盖最终显示规则。

## 5. 风扇安全

`AD_fan_deal()`保持固定占空比无刷成熟顺序：

```text
启动：FAN_ON = 1 -> 等待下一个10ms调用 -> 开PWM
关闭：先关PWM/升压 -> 等待下一个10ms调用 -> FAN_ON = 0
```

`AD_FAN`每次只在新的平均结果就绪时累加一次超压确认。以下状态都会清除`too_big_cnt`和采样就绪标志：

- ADC初始化。
- 风扇关闭或错误状态。
- 开启`FAN_ON`但PWM尚未启动。
- 检测电压恢复正常。
- 睡眠前。

占空比曲线由配置中的`base_count + fan_mode / gear_divisor`生成，规划阶段验证最大档结果不超过PWM周期。

## 6. 电量系统

保持成熟函数链：

```text
ADC_Sample() -> ADC_BAT_VALUE -> v_bat_deal() -> 定时追赶charge_num
```

生成器在生成时计算五段映射步长并写成整数常量，运行时不执行阈值除法。映射阈值必须严格单调。

`v_bat_deal()`：

- 先把电量ADC换算到成熟项目使用的标度。
- 根据最大档等分出五档负载补偿区间。
- 分别叠加风扇和制冷压降补偿。
- 判断低电、零电并执行分段百分比映射。
- 自检期间绕过慢追赶，直接初始化`charge_num`。
- 插入状态只在既有充电/充满定时分支中上升。
- 未插入状态只允许向`p_temp`下降，不允许电压回升后直接增加显示电量。

所有阈值、补偿和追赶时间都是产品标定参数，生成器只保证结构和约束，不替代放电曲线测试。

## 7. 睡眠

进入睡眠前必须满足：

- 无低电提示、风扇、充电和未完成按键事件。
- 唤醒保护计数已经结束。
- PWM、Timer3运行使能和`FAN_ON`均已关闭。

这保证无刷关闭的10ms顺序不会被睡眠直接跳过。

睡眠函数清空显示、按键、ADC和超压连续状态，应用统一规划的睡眠GPIO与唤醒掩码；唤醒后重新初始化并保留200ms保护时间。

## 8. 当前限制

- 未经过本机HSIDE/PICC真实编译。
- 未完成任何具体PCB的电池、风速、超压阈值和显示映射实测。
- 本文审查的双数字按键基线配置不包含有刷/无刷检测、AD按键、编码器、滑动变阻器等可选输入；这些能力由各自独立配置和审查文档覆盖。
- 当前生成器仍不支持纯有刷、雾化、RGB、多档PWM照明、通信或其他灯板；数字LED随风扇、独立开关和闪烁模式已经支持。
- 输出使用`.c.in/.h.in`，避免本机透明加密拦截并污染仓库。

完整配置是可审查的大型产品框架，不是无需验证即可量产的固件。
