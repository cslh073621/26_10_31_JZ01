# 无刷过压保护必须连续多次确认

2026-10-20 用户明确要求：确认次数必须大于1，不能以单个平均结果立即关机。

`fan_voltage_protection.consecutive_confirmations` 合法范围为 **2～255**。全部随附启用保护的配置统一采用 **13**，与成熟 `26_07_21_F824/project/main.c` 的计数行为相同；加载值1、0或256时直接报配置错误，不生成固件。不在生成器中静默修正非法参数。

计数单位是新的有效 AD_FAN 平均结果，不是原始ADC转换次数，不是自由主循环次数，也不是样本最大最小差。连续性规则如下：

- 有效平均值严格大于过压阈值：计数递增。
- 递增后的计数达到13：关机。因此第1～12次超限保持运行，第13次关机。
- 有效平均值小于或等于阈值：计数立即清零，下一次超限从1开始。
- 初始化、风扇关闭及原有检测非活动分支按既有逻辑清零；固定电压路径的 ready 结果消费一次后清除，不重复计数。

F824原码是 `if(too_big_cnt < 12) too_big_cnt++; else ...`，从0开始，第13次进入关机分支。FanForge是先递增、再比较 `>= AD_FAN_CONFIRM_COUNT`，所以等价参数应填写 **13，不能填12**。生成源码在宏定义旁标注这一规则。

这是保护确认策略修改。过压ADC阈值、ADC参考、平均窗口、采样节拍、PWM、启停顺序均不因此改变；本次未增加启动屏蔽或丢弃启动窗口。实际确认延时取决于产品有效均值的产生和消费周期，不应当把13次写成通用固定毫秒数。

2026-10-20验证：配置上下边界2/255通过，0/1/256拒绝；全部启用保护的随附配置为13，154项单元测试通过。SCX688W正式版及诊断版同步为13，诊断实际编译指令验证前12次不关、第13次关机、正常值清零及重复调用不重复计数。
