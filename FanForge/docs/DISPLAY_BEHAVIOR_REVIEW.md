# 显示页面行为审查

## 目标

显示行为模块只决定档位页、电量页和常态页之间的切换，不改变188灯板段位映射、充放电判断、电量分段或按键消抖结构。

## 当前策略

### 旧策略

`gear_3s_battery_3s_gear`保持原有成熟结构：

1. 开机或调档后显示档位。
2. 3s后显示电量。
3. 再过3s回到档位。
4. 插入充电器后常态显示电量，调档时短暂显示档位。

旧配置继续共用原有3s时间资源，生成的运行源码保持不变。

### 参数策略

`gear_event_battery_preview_idle`支持：

- `gear_event_ms`：开机或调档后的档位页时长。
- `normal_battery_preview_ms`：非充电状态下电量预览时长。
- `normal_idle_page`：非充电常态显示档位或电量。
- `charging_idle_page`：充电常态显示档位或电量。

典型配置为档位显示3s、电量显示5s、非充电常态档位、充电常态电量。

## 运行结构

- `show_mode_change()`启动或重启页面序列，并清除该序列拥有的时间资源。
- `mode_change_show()`消费生成的页面时间标志，推进`show_mode`和`step_cnt`。
- `mode_change()`在插拔充电、关风扇和低电等最终状态发生变化时，清除无效页面序列并选择对应常态页。
- `show_mode_deal()`只根据最终`show_mode`生成`Data[0..2]`，继续采用局部变量加短暂关中断的原子更新。

生成器不会为页面策略新增运行时tick计数器或新的显示状态机。

## 生成期约束

- 所有页面时间必须是10ms整数倍。
- 档位事件页范围为10ms到120s。
- 电量预览可关闭。
- 非充电常态已经是电量页时，禁止再配置电量预览周期。
- 页面时间角色不同，即使周期相同也不会错误共用可独立复位的计数器。

## 保持不变

- `smg_close()`和`smg_188_scan()`不处理页面业务。
- 电量映射、负载补偿和充放电追赶不变。
- CHRG/STDBY及INSERT/CHRG真值表不变。
- 固定占空比、7+3调压、16V保护和无刷10ms启停顺序不变。
- 睡眠GPIO和唤醒来源不由页面策略改写。
