# 制冷与LED可选功能审查

## 1. 适用范围

本模块只在产品配置明确启用制冷或LED时生成。它不把有无检测强加到所有风扇项目，也不改变电量、PWM、AD_FAN、显示扫描或风扇启停结构。

## 2. 上电有无检测

检测沿用成熟风扇项目的控制脚探测方式：

1. 上电全亮自检期间，输出锁存先写低。
2. 控制脚切换为输入并打开内部上拉。
3. 等待4个NOP让电平稳定。
4. 读取低电平表示存在MOS管下拉电阻，即对应功能存在。
5. 关闭内部上拉，恢复输出方向并拉低。

生成源码统一规定：

- `YOUWU_COOL=1`：存在制冷功能。
- `YOUWU_LED=1`：存在LED功能。
- 标志为0时，按键动作和输出归一化都不得再次打开对应输出。

检测安排在自检最后一个10ms周期，既不干扰前面的全亮检查，也不会进入自由运行主循环反复采样。

## 3. 制冷控制

`toggle_while_fan_on`保留经典项目结构：按键只在风扇已开、功能存在且满足充电策略时切换`COOL_EN`。`mode_change()`统一处理风扇关闭、零电、故障和充电禁用的连锁关闭。

`follow_fan`不生成制冷切换动作，由`mode_change()`直接按照风扇状态、功能检测结果和充电策略输出高低电平。

`allow_while_charging=false`是默认值。设为`true`只放开制冷输出，不改变充电限档、电量补偿和显示状态。

## 4. LED模式

- `fan_sync`：功能存在且风扇开启时输出高，风扇关闭时输出低。
- `on_off`：`light_cycle`短按动作在关和常亮之间切换。
- `on_off_flash`：`light_cycle`按关、常亮、500ms闪烁顺序循环。

独立LED模式使用`light_mode`并加入睡眠门槛；`fan_sync`不生成该变量。所有模式在睡眠入口和系统安全初始化中都强制输出低。

## 5. 保持不变

- `ADC_Sample()`、`v_bat_deal()`及充放电追赶结构不变。
- 风扇固定占空比或7+3调压算法不变。
- 无刷`FAN_ON -> 10ms -> PWM`启动和`PWM关闭 -> 10ms -> FAN_ON关闭`停机顺序不变。
- 188数码管扫描映射不变。
- 制冷压降补偿仍只看最终`COOL_EN`状态。
