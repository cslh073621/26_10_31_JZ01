# 初版模块审查

## 目的

这一版不是完整风扇产品，而是先证明以下生成链能够稳定工作：

```text
产品参数和物理脚位
    -> 固定功能模块声明资源
    -> 公共资源规划器检查能力和冲突
    -> 计算直接寄存器值
    -> 填入唯一 HS2811 核心模板
    -> 输出源码预览、解析计划和审查报告
```

配置不能指定模板、历史项目或函数版本。

## 当前固定模块

当前只启用 `brushless_fixed_duty` 无刷风扇模块：

- `FAN_ON`：普通 GPIO，先拉高使电机负极持续导通。
- `PWM_FAN`：Timer3 硬件 PWM，控制无刷升压电路。
- `AD_FAN`：检测分压后的风扇电压，用于超压保护。
- `fan_control_tick`：每 10ms 调用一次 `AD_fan_deal()`。

模块只提交资源请求。GPIO、PWM、ADC 和时间寄存器由公共规划器统一生成。

## 已确认的启停行为

启动：

```text
第一次 10ms 调用：FAN_ON = 1，立即返回
第二次 10ms 调用：写 PWM 占空比并开启 Timer3 PWM
```

关闭：

```text
第一次 10ms 调用：关闭 Timer3 PWM，清空占空比，立即返回
第二次 10ms 调用：FAN_ON = 0
```

因此启动和关闭均保留约 10ms 的无刷安全顺序，不增加额外状态机或等待变量。

## AD_FAN 保护

- ADC 切换后先丢弃配置的样本数。
- 对配置的有效样本数进行累加和二次幂右移平均。
- 生成前计算 `4095 * average_samples`，超过 `u16` 时拒绝生成。
- 超压样本需要连续达到配置次数才置错误、关 PWM 并请求关机。
- 风扇关闭、ADC 初始化和睡眠清理时均清零 `too_big_cnt`。

超压阈值仍是产品硬件参数，正式项目必须根据分压电阻和目标保护电压确定。

## 时钟说明

- `oscillator_hz` 是外设使用的振荡源频率。
- `system_divider` 决定 `Fcpu`，但它是 HSIDE/烧录配置，不是 `OSCM` 的运行时位。
- 生成代码写 `OSCM = 0x00` 选择高速模式。
- 生成报告明确列出必须匹配的工程系统分频。
- Timer1 和 Timer3 均根据配置计算，不复制历史项目常量。

## 当前边界

- 没有输入模块，所以生成的风扇默认关闭，无法由产品输入开启。
- 没有显示、电量、充电、制冷或睡眠唤醒业务。
- 睡眠资格表达式固定为假。
- 没有有刷或有无刷兼容逻辑。
- 当前输出是 `.c.in` 和 `.h.in`，避免本机透明加密拦截 Python 写入。

只有在这些边界和当前生成方式审查通过后，才进入下一个功能模块。
